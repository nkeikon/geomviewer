# viewgeom

> A lightweight command-line viewer for vector geospatial data (Shapefile, GeoJSON, GeoPackage, GeoParquet, KML/KMZ) with a simple Qt window, attribute filtering (pandas or DuckDB SQL), and export to QGIS.

viewgeom is built by Keiko Nomura. It follows from viewtif, the raster viewer by the same author.

## Installation

```
pip install viewgeom
pip install "viewgeom[parquet]"   # GeoParquet support
pip install duckdb                # --duckdb support
```

Requires a graphical display environment.

## Quick Start

```
viewgeom gadm41_JPN_1.json
viewgeom landuse.shp --column area_sqkm
viewgeom countries.gpkg --layer ADM_ADM_2
viewgeom earthquake.geojson --filter "mag > 5"
viewgeom earthquake.geojson --duckdb "SELECT * FROM data WHERE mag > 5" --qgis
viewgeom earthquake.geojson --duckdb "SELECT mag FROM data WHERE mag > 5" --save filtered.geojson
```

## Use with Claude Code

viewgeom has a Claude Code skill that lets Claude offer quick visual previews of vector files it works with. It is a separate install from the pip package:

```
mkdir -p ~/.claude/skills/viewgeom
curl -o ~/.claude/skills/viewgeom/SKILL.md https://raw.githubusercontent.com/nkeikon/geomviewer/main/skills/viewgeom/SKILL.md
```

Start a new Claude Code session after installing. The skill is at skills/viewgeom/SKILL.md in the GitHub repository.

## Related Tools (by the same author)

- viewtif: raster viewer (GeoTIFF, NetCDF, HDF, File Geodatabase)
- viewinline: non-interactive previews inside the terminal
